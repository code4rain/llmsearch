# llmsearch 로드맵 — M6~M9 (2026-08-29)

M1~M5(스펙 `2026-08-17-llmsearch-design.md`)가 전부 머지된 뒤의 추가 기능 로드맵. 사용자 결정: 네 방향 전부 진행, 아래 순서로. 각 마일스톤은 별도 스펙 → 3관점 리뷰 → 계획 → SDD 실행 → E2E → 머지 절차를 따른다.

| 순서 | 마일스톤 | 내용 | 의존 |
|---|---|---|---|
| M6 | 운영 완성 (스펙 잔여 P1) | 설정 탭 rules.md 편집, 문서별/전체 재요약, rebuild 재구축, 사용량 GUI 표시 | 없음 — 스펙 `2026-08-29-llmsearch-m6-design.md` |
| M7 | 검색 품질·평가 | 채팅 필터 UI(소스·날짜·발신자 → 선검색 강제 조건·툴 검색 기본값), 골든 평가 GUI(상위 3위 적중률·질문별 순위), 출처 카드에 매칭 청크 발췌 | 없음 |
| M8 | 채팅 UX | 대화 세션 저장/목록/불러오기(별도 `chats.db` — 인덱스는 소모품이라 rebuild에 지워지지 않게), 답변 내보내기(md → `data_dir/exports/`, notes 인덱싱 옵션), 출처 본문 미리보기 패널 | 없음 |
| M9 | 확장 | 로컬 임베딩 bge-m3 — **실노트북 스파이크 먼저**(CPU 속도·메모리), 성립 시 `LocalEmbeddings` + `embed_provider` 설정. 차원 변경으로 schema 버전 상승 | M6 rebuild |
| (파킹) | 회사 일정 시스템 커넥터 | 사내 API 엔드포인트·인증 방식 정보가 있어야 설계 가능 — 정보 입수 시 M9에 편입 | 사용자 정보 |

원칙: 스펙 §2 Out of Scope(다중 사용자·원격·쓰기 기능·모바일)는 유지. 각 마일스톤은 완료 시점부터 독립적으로 유용해야 한다.
